# 🚀 HCL Java Full Stack Training

Welcome to the **HCL Java Full Stack Training Repository**.

This repository contains structured **training notes, presentations, practical programs, assignments, projects, and reference materials** used throughout the Java Full Stack training program.

The goal of this repository is to provide a centralized learning resource where students can access course materials, practice programming, complete assignments, and work on real-world projects.

## 🎯 Training Objectives

By the end of this training, learners will be able to:

- Understand Core Java programming concepts
- Develop object-oriented Java applications
- Work with databases using SQL and MySQL
- Build RESTful APIs using Spring Boot
- Implement authentication and authorization
- Develop responsive web interfaces
- Work with JavaScript and React
- Use Git and GitHub for version control
- Containerize applications using Docker
- Perform application testing
- Understand cloud deployment concepts
- Develop and deploy full-stack applications
- Work on industry-oriented projects
